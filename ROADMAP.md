### R1. More fields (requested 2026-11-13; complete list added 2026-11-14)
The method is field-generic under (H1), (H2) and (N2) (paper, Part I).

**Complete scope.** There are exactly 16 norm-Euclidean real quadratic fields (Chatland–Davenport 1950; Barnes–Swinnerton-Dyer 1952; survey: Lemmermeyer 1995): ℚ(√d) for d ∈ {2, 3, 5, 6, 7, 11, 13, 17, 19, 21, 29, 33, 37, 41, 57, 73}. Of these, exactly 8 also have a unit of norm −1, so satisfy (N2):

| d | ω | (c0, c1) | fundamental unit (norm −1) | status |
|---|---|---|---|---|
| 2 | √2 | (2, 0) | 1 + √2 | done (validation; 146 classes) |
| 5 | (1+√5)/2 | (1, 1) | φ | done (144 classes) |
| 13 | (1+√13)/2 | (3, 1) | 1 + ω = (3+√13)/2 | provisional (39 classes; 2 candidates in a 12 h run) |
| 17 | (1+√17)/2 | (4, 1) | 4 + √17 = 3 + 2ω | to do (needs the prerequisite below) |
| 29 | (1+√29)/2 | (7, 1) | (5+√29)/2 = 2 + ω | to do (needs the prerequisite below) |
| 37 | (1+√37)/2 | (9, 1) | 6 + √37 = 5 + 2ω | to do (needs the prerequisite below) |
| 41 | (1+√41)/2 | (10, 1) | 32 + 5√41 = 27 + 10ω | to do (needs the prerequisite below) |
| 73 | (1+√73)/2 | (18, 1) | 1068 + 125√73 = 943 + 250ω | to do (needs the prerequisite below) |

**Prerequisite for d = 17, 29, 37, 41, 73.**
- Division with remainder by rounding coordinates bounds |N(remainder)| by d/16 · |N(divisor)| for ω = (1+√d)/2, and by d/4 for ω = √d. This is below 1 only for d ∈ {2, 3, 5, 13}.
- **Python:** `zphi/ring.py` `ediv` must search the nearby quotients, keeping one with |N(r)| < |N(b)|. The existing guard already raises if rounding fails.
- **Lean:** (H1) needs a new proof for these rings, since `BoxBound` fails. Published proofs (d = 73 especially) are delicate. Fallback: prove only that O is a PID, if the formal development needs nothing stronger.

**Later (outside the method as stated).**
- The 8 norm-Euclidean fields without a unit of norm −1, d ∈ {3, 6, 7, 11, 19, 21, 33, 57}: (N2) must first be removed from Part I.
- Relaxing (H1) to class number 1 would bring in more fields. Finiteness is then not guaranteed (it is open whether there are infinitely many real quadratic fields of class number 1).
- Fields of degree > 2 would need (H2) dropped.

**Paper:** the introduction ("The fields in scope") states the list of 16, the 8 in scope, and the prerequisite.

### D1. Higher-dimensional extensions (requested 2026-11-13)
Each reflective rank-3 lattice L found here is the root of a series

    L_k = L ⊕ ⟨1⟩^k   (append x_{3}², …, x_{2+k}²),   k = 0, 1, 2, …,

of hyperbolic lattices of rank 3 + k (ℍ^{2+k}).
- **Goal:** for every reflective class, and for every field, determine the largest k for which L_k is reflective.
  - Reflective L_k must be certified by a chamber.
  - The first non-reflective L_k must be certified by a non-reflectivity witness.
- **Justification for stopping at the first failure:** a result of Bugaenko, cited by Mark, shows that non-reflectivity propagates upwards in k: if L_k is not reflective, then neither is L_{k+1}.
  - **Located:** Bugaenko 1990, Theorem 2, restated as Mcleod's thesis Theorem 3.0.8 (`papers/mcleod_thesis_2013.txt`). If f = f′ ⊕ ⟨unimodular⟩, the polytope of f′ is a face of that of f; hence L_k non-reflective ⇒ L_{k+1} non-reflective. This holds for any hyperbolic f′, not only diagonal ones. To be checked against Bugaenko's original.
  - **Known anchors over ℤ[φ]** (Mcleod §3.2; his f_dⁿ has n squares, so n = 2 + k):
    - ⟨−φ,1,…⟩: reflective for n ≤ 7 (Bugaenko 1984), so k_max = 5;
    - ⟨−(3+2√5),1,…⟩: reflective at n = 2, not at n = 3 (loxodromic isometry), so k_max = 0;
    - ⟨−(−3+2√5),1,…⟩: reflective at n = 3 (a cube), higher n open, so k_max ≥ 1.
  - These are regression anchors for D1, and prior results for D2.
  - The exact statement, its hypotheses (for example whether it needs ⟨1⟩ summands specifically, or uses the face orthogonal to a root), and the precise reference must be confirmed from the source before use. See OPEN_QUESTIONS Q9.
  - Candidate sources:
    - Bugaenko, Moscow Univ. Math. Bull. 39 (1984);
    - Bugaenko, Selecta Math. Soviet. 9 (1990) 263–271;
    - Bugaenko, *Arithmetic crystallographic groups generated by reflections, and reflective hyperbolic lattices* (1992).
  - Mark's arXiv paper cites all three, but in the text we have only for the modification of Vinberg's algorithm.
- **Order (user, 2026-11-13):** start with the diagonal forms ⟨−d,1,…,1⟩, which AlVin handles, to reduce the computational burden. Non-diagonal classes come after.
- **Tools:**
  - AlVin covers diagonal L, which includes the 38 classes ⟨−d,1,1⟩ over ℤ[φ] and their analogues over the other fields.
  - Non-diagonal L ⊕ ⟨1⟩^k needs a Vinberg implementation for a general Gram matrix in rank ≥ 4 (Bugaenko's version for totally real fields), plus non-reflectivity certificates in higher rank. Neither exists yet: our Vinberg code is rank 3 only.
  - Vinberg's bound (no reflective arithmetic forms in dimension ≥ 30) caps k.
- **Paper:** a new Part or section, "Higher-dimensional extensions", with a table of k_max per class (stub added 2026-11-13).

### D2. Novelty check against the literature (requested 2026-11-13)
For every reflective form found (rank 3, and the higher-dimensional ones from D1), determine whether it is new.
- **Sources to compare against:**
  - Bugaenko (1984, 1990, 1992);
  - Guglielmetti's thesis and the AlVin data;
  - Mcleod's thesis;
  - Mark (2018) for ℤ[√2];
  - Nikulin;
  - Belolipetsky's survey and the references in these.
- **Method:** compare up to isometry. Use invariants first (determinant ideal, chamber shape), then explicit isometries, as in gate A.3.4.
- **Output:** a per-form column "known (reference) / new". A form counts as new only if it is absent from every source checked; record which sources were checked.
- **Paper:** add the column to the tables, and a summary of what is new.
